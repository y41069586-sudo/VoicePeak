WORKFLOW 4: RELEASE (TESTFLIGHT)
=================================
Purpose: Sign IPA + upload to TestFlight
Time: 30-40 minutes
Tag trigger: v* (e.g., v0.1.0, v1.0.0)

Prerequisite:
  - Codemagic App Store Connect integration configured (named "Verite 1")
  - Signing certificate + provisioning profile in App Store Connect

Commands:
  1. brew install xcodegen
  2. xcodegen generate --spec project.yml
  3. xcode-project use-profiles
     (Auto-downloads signing profiles from App Store Connect)
  
  4. xcodebuild test \
       -project "Verite.xcodeproj" \
       -scheme "Verite" \
       -configuration Release \
       -destination 'generic/platform=iOS Simulator' \
       -verbose
     (Final verification before release)
  
  5. xcode-project build-ipa \
       --project "Verite.xcodeproj" \
       --scheme "Verite" \
       --config Release \
       --archive-xcargs "CURRENT_PROJECT_VERSION=$BUILD_NUMBER"
     (Build + sign IPA)
  
  6. TestFlight upload (automatic via codemagic.yaml)

COREML HANDLING IN CI
====================

Scenario 1: No .mlmodelc in Bundle (CI Environment)
  1. SkinAnalysisEngineCoreML.analyze() called
  2. Heuristic baseline always computed
  3. ModelLoader.loadModel() returns nil
     (file not found - expected)
  4. mode == .hybrid, so fallback triggered
  5. HybridFusionEngine.fuseScores() gets:
     - heuristicResult: valid (computed in step 2)
     - coreMLResult: nil/empty (model not available)
  6. Returns: heuristic result as baseline
  7. Test verifies: result is not nil, is correct type
  
  Outcome: ✓ Test PASSES
           ✓ No crash
           ✓ Fallback verified

Log output (expected):
  [CoreML] ⚠️  Failed to load CoreML model: SkinAnalysisModel not found in bundle
  [CoreML] ℹ️  Falling back to heuristic analysis
  
  (Not an error, informational only)

Scenario 2: With .mlmodelc in Bundle (Production)
  1. ModelLoader.loadModel() succeeds
  2. InferencePipeline.infer() runs ML model
  3. Predictions return with confidence scores
  4. HybridFusionEngine blends ML + heuristic
  5. Returns: fused predictions
  
  Outcome: ✓ ML predictions used (weighted)
           ✓ Heuristic provides baseline safety
           ✓ Best of both

COMMON ERRORS & FIXES
=====================

Error: "xcodegen: command not found"
  Fix: brew install xcodegen (in codemagic.yaml script)

Error: "Cannot find VeriteTests target"
  Fix: Regenerate project: xcodegen generate --spec project.yml
       Check project.yml has both Verite and VeriteTests targets

Error: "Test suite 'VeriteTests' failed"
  Fix: Check test sources are in Verite/**/*Tests.swift
       Run locally to debug: xcodebuild test -project Verite.xcodeproj -scheme Verite

Error: "CoreML model not found in bundle" (in tests)
  Status: EXPECTED IN CI
  Fix: None - this is correct behavior (fallback tested)
       Verify tests still pass (if they fail, fallback logic broken)

Error: "Code signing required for Release"
  Fix: For release workflow only, requires App Store Connect integration
       For archive workflow, use CODE_SIGNING_ALLOWED=NO

Error: "TestFlight upload failed"
  Fix: Check integration name in codemagic.yaml matches Codemagic UI
       Check bundle ID: com.verite.com
       Check certificate + profile valid in App Store Connect
